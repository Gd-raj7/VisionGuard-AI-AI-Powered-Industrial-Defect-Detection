# VisionGuard AI

AI-powered industrial defect detection and localization using computer vision and deep learning.

## Project Goals
- Detect anomalies in industrial product images.
- Localize suspicious regions using anomaly heatmaps.
- Evaluate detection and localization performance.
- Provide a REST API using FastAPI.
- Build an interactive React dashboard.
- Maintain inspection history and reports.

## Technology Stack
- Python
- PyTorch
- OpenCV
- FastAPI
- React + Vite
- SQLite (planned)
